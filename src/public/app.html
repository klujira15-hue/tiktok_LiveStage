ขั้นที่ 2

ลิงก์หน้าเวที

ใส่ใน TikTok LIVE Studio → เพิ่มแหล่ง “Link” แล้ววางลิงก์นี้

-

พรีวิว: หน้าต่างเล็กลอยบนสุด ไว้ดูหน้าเวทีและทดสอบระหว่างไลฟ์ (ปิดเสียง) • ห้องควบคุม: เชื่อมต่อไลฟ์ก่อนถึงจะเปิดได้ — เด้งขึ้นเองตอนเชื่อมต่อ

  • Custom resolution: เปิด แล้วใส่ W 1080 × H 1920 กด Apply → กดลูกศร ˅ ข้างปุ่มปรับขนาด (⤢) ในแถบเครื่องมือด้านบน แล้วเลือก Fill ภาพจะเต็มจอไม่มีขอบ (อย่าเลือก Stretch ภาพจะยืดผิดสัดส่วน)
  • Turn on sound: ขึ้นกับการตั้งค่าเสียงของ LIVE Studio แต่ละเครื่อง — ถ้าเสียงซ้อนสองชั้นให้ลองปิด ถ้าไม่มีเสียงในไลฟ์ให้ลองเปิด (ลองสลับแล้วฟังจากมือถืออีกเครื่อง)
  • Always keep active: เปิด • กด Apply แล้วคลิกขวาที่ภาพ → Interact → คลิกในจอ 1 ครั้ง (เปิดเสียง)
  • ห้ามเปิดหน้าเวทีซ้อนกันหลายที่ (เสียงจะพูดซ้อน)

ข้อจำกัดการใช้งาน (อ่านก่อนไลฟ์)
  • เสียงพูดอัตโนมัติ ใช้บริการอ่านออกเสียงฟรีของ Microsoft Edge ซึ่งไม่ใช่บริการทางการสำหรับโปรแกรมอื่น — อาจช้า ใช้ไม่ได้ชั่วคราว หรือเลิกให้บริการได้ทุกเมื่อ ถ้าใช้ไม่ได้ระบบจะสลับไปใช้เสียงของเครื่องให้เอง
  • การอ่านคอมเมนต์/ของขวัญจาก TikTok ใช้ตัวเชื่อมที่ไม่ใช่ API ทางการของ TikTok — ถ้า TikTok เปลี่ยนระบบอาจใช้ไม่ได้จนกว่าจะอัปเดตโปรแกรม (รุ่น Local ปิดการอัปเดตจากผู้พัฒนาเดิม)
  • รุ่น Local ไม่ใช้บัญชีผู้พัฒนาเดิม • ใช้อินเทอร์เน็ตเฉพาะการเชื่อมต่อไลฟ์และบริการที่เลือกใช้
  • รุ่น Local นี้ไม่ได้เกี่ยวข้องหรือรับรองโดย TikTok — ผู้ไลฟ์ต้องทำตามกฎชุมชนของ TikTok เอง

เลือกธีม

วิดเจ็ตไลฟ์เกม

ไลฟ์เกมหรือไลฟ์แนวนอนที่ไม่อยากใช้ฉากเต็มจอ: ใช้วิดเจ็ตพื้นโปร่งใสวางทับภาพเกมแทน — ใน LIVE Studio เพิ่มแหล่ง Link ทีละอัน วางลิงก์ แล้วลากขนาด/ตำแหน่งตามชอบ (ใน OBS ใช้ Browser source)

ตัวเลือกต่อท้ายลิงก์: &scale=1.5 ขยายตัวหนังสือ • &tts=1 ให้ Alert พูดขอบคุณ (อย่าเปิดพร้อมหน้าเวทีเต็ม เสียงจะซ้อน) • &min=10 Alert เฉพาะของขวัญตั้งแต่ 10 เพชร • &n=5 จำนวนแถว (แชท/อันดับ)
ถ้าพื้นหลังไม่โปร่งใสใน LIVE Studio ให้ลองตั้ง Custom resolution ของแหล่ง Link ให้พอดีกับวิดเจ็ต หรือใช้ OBS ส่งภาพเข้า LIVE Studio

ขั้นที่ 3 จาก 4

ใส่หน้าเวทีใน TikTok LIVE Studio

-
  1. เปิด LIVE Studio → เพิ่มแหล่งที่มา → เลือก Link แล้ววางลิงก์
  2. เปิด Custom resolution ใส่ 1080 × 1920 กด Apply แล้วเลือก Fill (ลูกศร ˅ ข้างปุ่ม ⤢ บนแถบเครื่องมือ)
  3. เปิด Always keep active → Apply → คลิกขวาที่ภาพ → Interact → คลิกในจอ 1 ครั้งเพื่อเปิดเสียง

ยังไม่ทำตอนนี้ก็ได้ — ลิงก์อยู่ที่หน้าหลักเสมอ

ลองเล่นดูก่อนไลฟ์จริง

กดปุ่มด้านล่าง แล้วดูในหน้าต่างพรีวิว (หรือใน LIVE Studio) ว่ามีคนดูเดินเข้ามาและของขวัญเด้งขึ้น

พร้อมไลฟ์เมื่อไร: เริ่มไลฟ์ใน LIVE Studio แล้วกด เชื่อมต่อ ที่หน้าหลัก

คลิปจริงจากหน้าเวที พร้อมดนตรีของฉาก • ดูตรงนี้ไม่เปลี่ยนเวทีที่ไลฟ์อยู่
