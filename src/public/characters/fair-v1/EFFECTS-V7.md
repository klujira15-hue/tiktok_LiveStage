# เอฟเฟกต์งานวัด v7

เปิด `/characters/fair-v1/effects.html` เลือกตัวละครและชื่อบนเอฟเฟกต์ แล้วเริ่มกิจกรรมได้ หรือกด “ชมทั้ง 3 กิจกรรม” เพื่อดูการทำงานร่วมกัน

## กระทง

เดินถึงขอบท่าน้ำ → คุกเข่าถือกระทง → ปล่อยเพียงหนึ่งครั้งหลังเตรียม 3 วินาที → กระทงแยกจากภาพมือ ค่อย ๆ ลงถึงผิวน้ำ → ลอยตามกระแสน้ำพร้อมคลื่นวงรี แสงเทียน เงาสะท้อน และชื่อผู้ปล่อย → ลอยออกจากฉาก ตัวละครลุกและกลับมาใช้ต่อได้

## ชิงช้าสวรรค์

ตัวละครเดินไปจุดคิว → รอกระเช้าว่างที่จุดขึ้น → วงล้อหยุดชั่วครู่ให้ขึ้น → ภาพนั่งอยู่ระหว่างกระเช้าด้านหลังกับราวด้านหน้า → วงล้อหมุนโดยกระเช้าและตัวละครยังตั้งตรง → ครบหนึ่งรอบกลับมาจุดเดิม → ลงกระเช้า ลุก เดินออก

วงล้อเป็นรูปทรงที่คำนวณตำแหน่งได้ใน canvas กระเช้าและราวเป็นภาพแยกชั้น ภาพพื้นหลังใหม่เอาชิงช้าติดภาพออกแล้ว เพื่อไม่ให้มีวงล้อเดิมซ้อนกับวงล้อที่เคลื่อนไหว มี 8 กระเช้า คิวเข้าเฉพาะช่องว่างและไม่รับตัวละครเดิมซ้ำขณะกำลังทำกิจกรรม

## โคม

เดินถึงจุดปล่อย → ถือโคม 3 วินาที → ภาพมือเปลี่ยนเป็นมือว่าง → โคมแยกออก ลอยสูงตามลม ขนาดเล็กลงและจางเมื่อออกไกล พร้อมแสงอุ่นและชื่อผู้ปล่อย

ปุ่ม “โคมเต็มฟ้า” เปิดฉากท้องฟ้ากลางคืนและปล่อยโคมหลายชั้นขนาด มีจังหวะขึ้นต่างกัน ก่อนเปลี่ยนกลับมางานวัด กิจกรรมเบื้องหลังเดินต่อระหว่างแสดงท้องฟ้า ไม่รีเซ็ตคิวชิงช้าหรือกระทง

## ภาพและเสียง

ภาพ background.png, sky.png และ props.png ใน `effects-v7/` สร้างด้วย built-in imagegen พรอมต์อยู่ใน `effects-v7/prompts.json` ภาพเดิมเก็บไว้ อุปกรณ์ใน props.png แบ่งเป็นกระทง โคม กระเช้าด้านหลัง และราวด้านหน้า พิกัดตัดแอตลาสกำหนดใน effects-page.js ให้ชั้นกระเช้าซ้อนตรงกัน

เปิดเสียงประกอบเบา ๆ ได้ด้วยช่องเลือกบนหน้า ใช้เสียงสังเคราะห์สั้น ๆ สำหรับจังหวะปล่อยและขึ้นกระเช้า วิดีโอ 40 วินาทีบันทึกภาพโดยไม่มีเสียง

ตัวเล่นหลัก `effects-engine.js` แยกข้อมูลกิจกรรมจากการวาดภาพ ใช้ request(index, type, name) สำหรับ wheel, water, lantern มี snapshot() และประวัติเหตุการณ์สำหรับตรวจหนึ่งครั้งต่อการปล่อย/ขึ้น/ลง
