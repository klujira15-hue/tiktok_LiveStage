# ชุดเต้นเสริมจากภาพผู้ใช้ v6

เพิ่มชุดเต้นเฉพาะตัว 4 ท่าต่อคน โดยใช้ภาพต้นฉบับของแต่ละคนตรงตามไฟล์ที่ผู้ใช้ส่งมา ลำดับท่าและจังหวะเก็บแยกใน `manifest.json > characters[].extraDance` ไม่ใช้ชุดภาพร่วมกันระหว่างตัวละคร

| ตัวละคร | ชุดเต้น | ลำดับ 4 ท่า | ระยะเวลาท่าละ (มิลลิวินาที) |
|---|---|---|---|
| หนุ่มหมวกฟาง | ลูกทุ่งขี้เล่น | เท้าเอวโยกเข่า → แตะส้นเท้า → ชี้สองมือ → ไขว้แขนเหนือศีรษะยกเข่า | 500 / 450 / 600 / 500 |
| สาวชุดไทย | รำไทยจีบมือ | วงแขนเหนือศีรษะ → จีบสองข้าง → ส่งมือคู่ไปหน้า → ตั้งวงข้างแก้ม | 900 / 800 / 1000 / 900 |
| สาวเสื้อชมพู | ป๊อปหวานสดใส | หัวใจระดับอก → แตะแก้มขยิบตา → ส่งจูบไขว้เท้า → ชี้มือก้าวแตะ | 650 / 550 / 650 / 500 |
| หนุ่มเสื้อลาย | ป๊อปสนุกมั่นใจ | กางแขนรับจังหวะ → แตะขมับ → ชูหมัดคู่ยกเข่า → ชูนิ้วโป้งก้าวสลับ | 500 / 450 / 550 / 450 |

ท่าไหว้จากภาพชุดไทยช่องแรกและภาพชุดชมพู/เสื้อลายช่องไหว้ถูกแยกออกจากชุดเต้นเสริม

## เล่นในหน้าทดลอง

- `danceExtra`: เต้นชุดใหม่ 4 ท่า วนตามจังหวะของแต่ละคน
- `extra1`–`extra4`: แสดงท่าเสริมแต่ละท่าค้างไว้เพื่อตรวจ
- `danceMix`: เล่นรำวงเดิม 4 ท่า ต่อด้วยชุดใหม่ 4 ท่า รวม 8 ท่าต่อคน
- “ชุดเต้นใหม่บนเวที” และ “รวม 8 ท่าบนเวที”: แสดงพร้อมกันในฉากงานวัด
- “วิดีโอชุดเต้น 16 วินาที”: บันทึกชุดรวมบนเวทีโดยไม่มีเสียง

ตัวเล่น `dance-extras.js` เลือกเฟรมจากภาพของเจ้าของตัวละคร รักษาขนาดต่อชุดและจุดเท้าเดิม การเคลื่อนไหวเป็นการเปลี่ยนภาพท่าตามจังหวะ ไม่มีการนำท่าเต้นไปใช้แทนท่าเดิน ท่าไหว้หันหาพระและกิจกรรมถืออุปกรณ์ยังใช้ระบบเดิม

ใช้กับเซิร์ฟเวอร์ LiveStage ที่มีอยู่ เปิด `/characters/fair-v1/preview.html` ชุดนี้ยังเป็นหน้าทดลอง ไม่เปลี่ยนการออก LIVE ปัจจุบัน
