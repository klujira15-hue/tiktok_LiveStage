# ท่าตัวละครงานวัด v3

ทั้ง 4 ตัวใช้ชื่อท่าและตำแหน่งช่องตรงกัน แต่ละไฟล์เป็น PNG โปร่งใส 4 คอลัมน์ × 3 แถว รวม 12 ภาพต่อตัว (48 ภาพใหม่) สร้างด้วย built-in imagegen โดยยึดหน้าตาและชุดจากภาพอ้างอิงเดิม พรอมต์ฉบับเต็มอยู่ใน `activity-prompts.txt`

| กิจกรรม | ลำดับที่ใช้ในหน้าทดลอง |
|---|---|
| ไหว้พระ | เดินถึงจุด → ย่อตัว → คุกเข่าพนมมือ → ลุกยืน |
| ขึ้นชิงช้า | เดินไปจุดคิว → ยืนรอ 2 วินาที → เดินไปจุดขึ้น → นั่งขาห้อย |
| ร้านค้า | เดินไปหน้าร้าน → ยืนชมร้าน |
| เวทีรำวง | เดินผ่านบันไดเวที → สลับท่ารำซ้าย–ขวา |
| จุดไฟเย็น | เดินถึงจุด → ถือก้านไฟเย็น → แสดงประกายที่ปลายก้าน |
| ปล่อยโคม | ถือโคม 3 วินาที → ยกมือปล่อย → โคมแยกจากมือและลอยขึ้น |
| ลอยกระทง | คุกเข่าถือกระทง 3 วินาที → ยื่นมือปล่อย → กระทงแยกจากมือและลอยออก |

| เลขเฟรม เริ่มที่ 0 | ภาพท่า |
|---|---|
| 0 | ยืนรอ |
| 1 | คุกเข่าไหว้พระ |
| 2 | นั่งกระเช้า มือบนตัก ขาห้อย ไม่มีเก้าอี้ติดภาพ |
| 3 | ย่อตัว / ลุกขึ้น |
| 4–5 | รำวงสองจังหวะ |
| 6–7 | ถือก้านไฟเย็นสองตำแหน่ง |
| 8 | ถือโคม |
| 9 | ยกมือว่างหลังปล่อยโคม |
| 10 | คุกเข่าถือกระทง |
| 11 | คุกเข่ายื่นมือว่างหลังปล่อยกระทง |

ไฟล์ภาพอยู่ใน `source/<character-id>-activities-v3.png` และผูกข้อมูลไว้ใน `manifest.json` ตัวเล่น `activity-runtime.js` แยกการเลือกท่ากับประกาย โคม และกระทงที่ลอยออกจากมือ ท่าเดินยังใช้ `walk-cycle-v2.png` ส่วนท่าอารมณ์เดิมยังอยู่ครบ

เปิด `/characters/fair-v1/preview.html` จากเซิร์ฟเวอร์ LiveStage แล้วเลือกท่ารายตัว หรือกด “ชมกิจกรรมต่อเนื่อง” วิดีโอที่ส่งออกแสดงท่ากิจกรรมใหม่ต่อเนื่อง 24 วินาที ไม่มีเสียง

ขอบเขตปัจจุบัน: เป็นภาพท่าและแอนิเมชันแบบสลับเฟรมในหน้าทดลอง ยังไม่ได้เชื่อมของขวัญหรือผู้ชม LIVE วงล้อและกระเช้าในภาพฉากยังไม่หมุน การรอคิว 2 วินาทีเป็นการสาธิต ไม่ใช่คิวผู้ชมจริง และยังไม่มีท่าหันหลังครบทุกทิศ
