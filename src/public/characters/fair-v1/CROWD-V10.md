# งานวัด v10: ยืนไหว้ / เต้นเฉพาะตัว / ไฟเย็น / โคมต่อเนื่อง

## ผลลัพธ์
- ตำแหน่งไหว้พระย้ายเข้าหน้าพระ: แถวหน้า 5 ช่อง แถวหลัง 5 ช่องสลับระหว่างช่องหน้า และแถวรอด้านหลัง ไม่มีช่องบริการอยู่ข้างกระถาง/ข้างทาง
- ภาพยืนพนมมือหันซ้ายเข้าพระใหม่ทั้ง 4 แบบ ท่าก้มเล็กน้อย 2 เฟรมต่อตัว ขายืนตลอด ไม่ใช้ชุดคุกเข่าหรือนั่ง
- ขนาดตัวละครในลานเพิ่ม 10% ขนาดกระเช้าและกลไกกระทงเดิมยังใช้เดิม
- เวทีใช้ danceExtra ซึ่งเป็น 4 ท่าเฉพาะตัวจากภาพต้นฉบับแต่ละชุด แยกเสื้อเหลืองลูกทุ่ง / ชุดไทยจีบมือ / เสื้อชมพูหัวใจแตะแก้ม / ชายลายสก็อตกางแขนแตะขมับ แต่ละตัวมีจังหวะและเวลาเริ่มต่างกัน ไม่ใช้สี่ท่ารำวงร่วมกันใน danceMix
- ไฟเย็น: รัศมีประกายยาวขึ้น แสงกลางขาวชัด มีแสงอุ่นรอบปลายก้าน ไม่เพิ่มเอฟเฟกต์ลอยกระทงหรือชิงช้าใหม่
- โคม: ปล่อยโคมเล็กจากมือก่อน เมื่อเส้นทางลอยขึ้นถึง y≈0.075 ใกล้ขอบบน ค่อยเปิดโคมเต็มฟ้าอัตโนมัติและเฟดเข้า ไม่ลบโคมเล็ก ไม่ลบปุ่มโคมเต็มฟ้าเดิม ไม่ต้องกดเอฟเฟกต์แยก
- แต่ละโคมผูกกับ id การปล่อยเดียว เล่นช่วงเต็มฟ้าครั้งเดียวต่อ id ถ้ามีหลายรายการระหว่างเต็มฟ้า จะเพิ่มโคมและต่อเวลาเอฟเฟกต์
