เลือกธีมไลฟ์

เปลี่ยนหน้ากากของไลฟ์ได้ตลอด กด "ใช้ธีมนี้" แล้วหน้าเวทีทุกจอ (รวมใน OBS / TikTok LIVE Studio) จะเปลี่ยนตามทันที ลิงก์เดิมไม่ต้องเปลี่ยน คนดูที่อยู่ในฉากและ Top 5 ยังอยู่ ส่วนของขวัญ ข้อความ และคำขอ แต่ละธีมตั้งแยกกันได้

เชื่อมต่อไลฟ์

ใส่ชื่อผู้ใช้ TikTok ของช่องที่กำลังไลฟ์ ระบบจะดึงคอมเมนต์ ของขวัญ ไลก์ และผู้ติดตามมาแสดงบนหน้าไลฟ์ทันที

Super Chat / Super Sticker = ของขวัญ (เทียบเป็นเพชร) • สมาชิกใหม่ = ผู้ติดตาม • YouTube ไม่ส่งหัวใจ/แชร์ • อ่านแชทจากหน้าเว็บสาธารณะ ไม่ใช่ API ทางการ

ถ้ายังไม่ได้เปิดไลฟ์ ระบบจะลองเชื่อมใหม่ทุก 20 วินาที

เอาหน้าเวทีไปขึ้นไลฟ์

หน้าเวทีอยู่ที่ ขนาด 1080×1920 (แนวตั้ง) — ใช้ลิงก์เดียวทุกธีม

  • OBS / Streamlabs: เพิ่ม Browser Source → ใส่ลิงก์ด้านบน → กว้าง 1080 สูง 1920 → ติ๊ก "Control audio via OBS" ถ้าต้องการเสียงเอฟเฟกต์
  • TikTok LIVE Studio: เพิ่มแหล่ง "ลิงก์ (Link)" → วางลิงก์ด้านบน → ตั้งขนาด 1080 × 1920 แล้วเลือก Fill (ลูกศร ˅ ข้างปุ่ม ⤢ บนแถบเครื่องมือ) ให้เต็มจอ (คมชัดเต็มที่ — อย่าใช้ Window Capture จะเบลอ)
    ถ้าในไลฟ์ไม่มีเสียง หรือเห็นป้าย "คลิกที่จอเพื่อเปิดเสียง": ใช้ลิงก์ stage.html?silent ในแหล่ง Link แทน แล้วเปิด stage.html อีกแท็บในเบราว์เซอร์ไว้ให้เสียงออก (คลิก 1 ครั้ง) ให้ LIVE Studio จับเสียงคอมพิวเตอร์
↗ เปิดหน้าเวที

📱 ไลฟ์จากมือถือ (แชร์หน้าจอ)

  1. ให้มือถือต่อ Wi-Fi เดียวกับคอมเครื่องนี้ (เน็ตมือถือ 4G/5G ใช้ไม่ได้)
  2. สแกน QR หรือเปิดลิงก์ - ในมือถือ
  3. แตะ "แตะเพื่อเริ่ม" → หน้าเวทีเต็มจอ เปิดเสียง กันจอดับ
    iPhone: กด แชร์ ⬆️ → เพิ่มไปยังหน้าจอโฮม แล้วเปิดจากไอคอน จะไม่มีแถบเบราว์เซอร์
  4. เปิด ห้ามรบกวน แล้วในแอป TikTok เลือกไลฟ์แบบ เกมมือถือ / แชร์หน้าจอ สลับกลับมาที่หน้าเวที

คุมหลังบ้านจากมือถืออีกเครื่องได้ที่ -
